# Scloudify

Scloudify is a web application that connects with **Spotify** and **SoundCloud** to let you explore, analyze, and compare your playlists.  
It provides a clean interface to view your music libraries, see detailed track insights (like danceability, energy, valence, and tempo), and soon will support side-by-side playlist comparisons across platforms.

Built with **React, TypeScript, and Tailwind CSS**, powered by the **Spotify Web API** and **SoundCloud API**.
